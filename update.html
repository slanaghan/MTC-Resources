Working with the spreadsheet

Which fields should I edit?

Sessions owns the title, short description, primary and additional focus areas, and topic tags. Separate multiple topics or tags with semicolons.

Offerings owns each date, program, presenter, review flag, source note, and resource folder URL. The export tool recalculates the session’s date summary, program list, number of offerings, and latest folder from these rows.

Resources lists individual files. Its Session IDs and Offering IDs connect those files to sessions. Adding individual files is optional when the session folder already contains the materials.

How do I add a new session or another date?
  1. For a new topic, add a row to Sessions. Give it a new Session ID, such as MTC-136. Never reuse an existing ID. Include its title, description, focus area, and tags.
  2. Add a row to Offerings with a new Offering ID, such as OFR-158. Enter the matching Session ID, start and end dates, date status, program, and resource folder URL.
  3. For an existing session offered again, add only an Offering row using its existing Session ID.
  4. Save the workbook, then check and export it here. The results will show the next available IDs based on your workbook.

Keep existing IDs when renaming sessions or sorting rows. Formula and date-summary columns on Sessions do not need to be recalculated for this export.

What about uncertain or missing dates?

Use real spreadsheet dates in Start date and End date. For a single day, use the same date in both columns. Date status distinguishes an Exact date, Institute window, Multi-day session, or Date conflict.

For a month-only date, leave the day fields blank and write a label such as 2026-09 (day unknown) in Date label. Set Review needed to Yes and explain the uncertainty in Source notes / review details. A date with no year can be labeled Unknown.

How do I remove a session?

Delete its row from Sessions and its matching rows from Offerings. You can keep the original files in Resources; the export tool removes references to deleted records and reports that cleanup.

How do I publish on GitHub Pages?
  1. Download the new sessions.json after the checks pass.
  2. Open your GitHub repository, enter the data folder, and choose Add file → Upload files.
  3. Upload the new sessions.json and commit the change. Use the same name to replace the existing file.
  4. Wait for GitHub Pages to finish publishing, then reload the session library.

This tool creates a download; it does not publish or change the live website. The public library reads only the published data file. If you distribute the workbook through this site, also replace the copy in downloads with your latest master.
